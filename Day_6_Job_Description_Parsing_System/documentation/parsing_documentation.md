# Job Description Parsing System

## 1. Project Overview

The Job Description Parsing System converts unstructured job
descriptions into structured, AI-readable data.

## 2. Objective

- Extract job roles from job descriptions.
- Identify technical skills and normalize skill synonyms.
- Extract required years of experience.
- Identify educational qualifications.
- Normalize job description text.
- Generate structured JSON output.

## 3. Modules

### jd_parser.py
Contains functions for text normalization, role extraction,
skill extraction, experience extraction, and education extraction.

### main.py
Runs the parser and saves the extracted information as JSON.

### data/sample_jds.txt
Contains the sample job description used as input.

### output/jd_output_samples.json
Stores the structured output generated by the parser.

## 4. Parsing Workflow

1. Read the job description.
2. Normalize the text.
3. Identify the job role.
4. Extract technical skills.
5. Extract experience requirements.
6. Identify educational qualifications.
7. Convert the extracted information into a structured object.
8. Save the output in JSON format.

## 5. Output Structure

The output contains:

- job_role
- required_skills
- experience
- education
- normalized_description

## 6. Limitations

This parser uses rule-based matching and regular expressions.
It may not identify every job title, skill, qualification,
or experience format. It does not use a trained AI model.

## 7. Conclusion

The system transforms raw job descriptions into structured
data that can be used by AI-based recruitment and job-matching
applications.

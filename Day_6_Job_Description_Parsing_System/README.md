# Job Description Parsing System

## About the Project

This project extracts structured information from job
descriptions using Python.

## Features

- Job role extraction
- Skill extraction and synonym normalization
- Experience extraction
- Education extraction
- Text normalization
- JSON output generation

## Project Structure

- main.py
- jd_parser.py
- requirements.txt
- data/sample_jds.txt
- output/jd_output_samples.json
- documentation/parsing_documentation.md

## How to Run

1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

   python main.py

## Output

The structured job description is saved in:

output/jd_output_samples.json

## Technologies Used

- Python
- Regular Expressions
- JSON

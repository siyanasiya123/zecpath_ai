# Zecpath AI Hiring Assistant

## Day 3 - Environment & Repository Setup

Zecpath is an AI-powered hiring platform.

This repository contains the basic modular structure for the project.

## Project Modules

- parsers - Document parsing
- ats_engine - ATS functionality
- screening_ai - Candidate screening
- interview_ai - Interview functionality
- scoring - Candidate scoring
- utils - Common utilities
- tests - Project tests
- data - Project data
- logs - Application logs

## Installation

Create virtual environment:

python -m venv .venv

Activate on Windows:

.venv\Scripts\activate

Install requirements:

pip install -r requirements.txt

## Run

python main.py

## Test

pytest
